# Roadmap de crecimiento — VetSaaS

Documento de trabajo para ir añadiendo producto y operación con foco en **crecer en Perú** (clínica PYME), retener clientes y diferenciarse de VetPraxis / GVET / Wirevet.

**Posicionamiento a defender**

> Sistema de clínica para Perú: caja + FEL + WhatsApp, listo en días, sin ERP caro.

**No es el objetivo** copiar el brochure completo de VetPraxis. El objetivo es ganar en **conversión, retención y operación diaria** del segmento Starter–Pro.

---

## Cómo usar este documento

1. Trabajar **una prioridad P0 a la vez** (o como máximo dos hilos si uno es comercial y otro técnico).
2. Cada ítem debería cerrar con: usable en producción + medible (uso real o impacto en churn/cierre).
3. Marcar al completar: `[x]` y fecha breve.
4. Revisar el orden cada 30–45 días según churn, demos y lo que piden los clientes que pagan.

---

## Norte (métricas)

| Horizonte | Meta orientativa |
|-----------|------------------|
| 30 días | Churn bajo control; onboarding 7 días; Meta solo Lima + Chiclayo |
| 90 días | ~25–30 clientes; CAC ≤ 1–1.5 meses de plan; referidos activos |
| 6 meses | Opción #1 en “clínica PYME Perú + WhatsApp + FEL” en tu red |
| 12 meses | SEO básico + una cara al tutor (link reservas o mini-portal) |

## P0 — Crítico para no perder / cerrar más (hacer primero)

### Producto

- [ ] **Confirmación de cita por WhatsApp (SÍ / NO / reprogramar)**  
  Liberar o marcar slot según respuesta. Reduce inasistencias (argumento fuerte vs competencia) sin necesidad de app tutores.

- [ ] **Pagos parciales / saldo pendiente / deudas en caja**  
  Hoy `/caja/pagos` es hueco. Dueños de clínica lo piden siempre. Cobra consulta/servicio aunque no paguen el 100 % al momento.

- [ ] **Onboarding guiado 7 días (producto + checklist)**  
  Obligar/guiar: sede → clínica → paciente → 1 venta (ticket o FEL) → 1 recordatorio WA. Dashboard ya tiene base; endurecer el flujo y alertas si no completan.

- [ ] **Alertas de cliente en riesgo**  
  Sin login X días, sin ventas, cita sin confirmar, suscripción por vencer → cola para ti (WhatsApp interno o panel plataforma/tenant).

### Comercial / operación (tú solo)

- [ ] Público Meta: **solo Lima + Chiclayo**; Advantage+ off; quitar intereses de dueños de mascotas / IT.
- [ ] Medir embudo: **chat → demo → pago** (no solo “conversaciones”).
- [ ] **Referidos**: 1 mes gratis o S/50–100 por clínica referida que pague el 1.er mes.
- [ ] Chiclayo: 1–2 medias jornadas/semana con visitas **con cita**.
- [ ] Lima: cierre remoto; 1 viaje/mes solo con agenda cerrada (6–8 citas).
- [ ] Entrevistas de churn (los que se van + 3–4 felices): por qué contrataron / qué no usan / qué los retendría.

## P1 — Diferenciación fuerte (siguiente bloque)

### WhatsApp / comunicaciones

- [ ] **Plantillas reutilizables** (recordatorio, post-consulta, cobro pendiente, grooming listo).  
  Hoy plantillas es placeholder. Suficiente para no depender de campañas Meta Business caras.

- [ ] **Cola de cobro por WhatsApp**  
  “Tienes saldo pendiente S/ XX — link o instrucciones de pago”.

- [ ] Mejorar bot clínica: **agendar / confirmar / reprogramar** con menos fricción (sin diagnosticar).

- [ ] Campañas **simples** (1 segmento, 1 mensaje): cumpleaños, vacunas vencidas, inactivos 60 días — con límites por plan.

### Caja / dinero

- [ ] Créditos / anticipos generalizados (no solo adelanto grooming): consulta, hotel, paquetes.
- [ ] Estado de cuenta del propietario (lo que debe / lo pagado).
- [ ] Alta libre de venta solo-servicio sin prefill (cuando no viene de consulta/grooming).
- [ ] Cierre de caja más “dueño-friendly”: resumen Yape/Plin/tarjeta/efectivo + PDF claro.

### Reportes (lo que el dueño mira)

- [ ] Ventas del día / mes por método de pago.
- [ ] Top productos y servicios.
- [ ] Ingresos por veterinario / groomer (si aplica).
- [ ] Inasistencias / citas no confirmadas.
- [ ] Export Excel de lo anterior (una pantalla “Reportes dueño”, no 10 módulos).

### Agenda

- [ ] **Horarios de atención** por sede / profesional (sacar placeholder).
- [ ] **Bloqueos** (feriados, vacaciones vet).
- [ ] Link de **reserva por WhatsApp** (el tutor elige hueco; confirma en el sistema).  
  Cierra ~70 % del gap “cita online 24/7” sin app móvil.

---

## P2 — Empate selectivo con competencia (cuando P0–P1 estén vivos)

### Cara al tutor (sin app nativa todavía)

- [ ] **Mini-portal web** (magic link): ver próximas citas, carnet vacunas, saldos, confirmar asistencia.
- [ ] Envío de receta / indicaciones / resultados lab con enlace seguro (además de PDF por WA).

### Clínica avanzada (priorizar por demanda real de clientes que pagan)

- [ ] Cirugías: protocolo pre / intra / post más completo.
- [ ] Hospitalización: evolución por horario + recordatorio staff (no inventar “WA automático diario” hasta que lo pidan).
- [ ] Laboratorio: estados más claros + plantillas de resultados.
- [ ] Consentimientos / certificados con datos precargados (PDF).

### Inventario / petshop

- [ ] Listas de precio / márgenes visibles en reportes.
- [ ] Kits / paquetes (vacuna + consulta, grooming + baño).
- [ ] Alertas de vencimiento más accionables (WhatsApp al admin de clínica).

### FEL / cumplimiento Perú

- [ ] Notas de crédito fluidas en el día a día (si el plan lo vende).
- [ ] Mejor UX de errores SUNAT / reintentos.
- [ ] (Solo si hay demanda) guías de remisión.

### Multisede / equipo

- [ ] Permisos más finos si clínicas medianas lo piden.
- [ ] Traslados de stock + reporte consolidado multi-sede para el dueño.

---

## P3 — Más adelante (no distraer ahora)

Hacer **solo** con ≥40–50 clientes estables o pedido fuerte de plan alto:

- [ ] App móvil tutores (tipo VetClick) — cara y de soporte alto.
- [ ] IA clínica (transcripción / sugerencia diagnóstica) — costosa; VetPraxis ya vive de eso.
- [ ] Telemedicina (Meet).
- [ ] Imagenología / PACS.
- [ ] Contabilidad completa (libro diario, CXP avanzada).
- [ ] White-label / API pública.
- [ ] Multi-país fiscal (otros regímenes distintos a SUNAT).
- [ ] E-commerce petshop.
- [ ] TikTok Ads como canal principal.
- [ ] Expansión a otro país.

## Checklist de lanzamiento por feature

Antes de marcar un ítem `[x]`:

1. [ ] Happy path en UI tenant
2. [ ] Permisos / feature de plan si aplica
3. [ ] i18n `es` (y `en` si el módulo ya está bilingüe)
4. [ ] Sin romper FEL / caja / stock
5. [ ] Nota breve en changelog interno o mensaje a clientes beta
6. [ ] Métrica: ¿alguien lo usó en 14 días?

## Plan sugerido por sprints (orientativo)

### Sprint A (2–3 semanas) — Retención + dinero
1. Pagos parciales / deudas  
2. Endurecer onboarding 7 días  
3. Alertas cliente en riesgo (mínimo viable)

### Sprint B (2–3 semanas) — WhatsApp citas
1. Confirmación SÍ/NO / reprogramar  
2. Plantillas básicas  
3. Ajuste embudo Meta + referidos (paralelo comercial)

### Sprint C (2–4 semanas) — Dueño ve números
1. Reportes dueño (día/mes, métodos, top)  
2. Horarios + bloqueos  
3. Link reserva WA (MVP)

### Sprint D — Según feedback de clientes que pagan
Elegir 2–3 de P2 (portal mínimo, paquetes, cirugías, etc.)

---

## Argumentario comercial (mientras construyes)

Usar en demos / WhatsApp **solo lo que ya existe**:

1. FEL Perú en el mismo flujo de cobro  
2. WhatsApp real: comprobantes, historias, grooming, recordatorios, bot  
3. Caja con Yape/Plin/mixto + prefills (consulta, grooming, hotel)  
4. Precio claro e instalación rápida  
5. Soporte cercano (tú)

No pelear: “tenemos más IA / app / países que VetPraxis”.

---

## Resumen ejecutivo

| Orden | Foco |
|-------|------|
| 1 | Retención + deudas en caja + confirmación citas WA |
| 2 | Plantillas WA + reportes dueño + horarios/reserva link |
| 3 | Mini-portal tutor y clínica avanzada **por demanda** |
| 4 | App / IA clínica / otro país — mucho después |

**Crecer = vender y retener en Lima remoto + Chiclayo presencial, mientras el producto cierra los 3 huecos que más duelen: deudas, confirmación de citas y visibilidad del dinero.**
